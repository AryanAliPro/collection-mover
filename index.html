Collection Mover

Open this app from your Shopify admin (Apps → Collection Mover). It only works embedded in a store.

Export

Download every collection from this store (this store) as an Excel file.


  


  

    
Import

    
Upload an exported file to create the collections in this store. Import your products first, so manual collections can find them.

    
    
    
    
    
    
    

  


  

    What gets copied
    
Copied: title, handle, description, image, SEO, sort order, theme template, metafields, sales-channel publishing, smart-collection conditions, and for manual collections the product list (matched by product handle). The file uses the same layout as a Matrixify collections export, so Matrixify files can be imported too.

    
Not copied: conditions that depend on a metafield definition, and products missing from this store (reported in the log).
